# 🚀 AI UI Component Generator

A dynamic web application that generates styled HTML & Tailwind CSS components on the fly using Artificial Intelligence (Groq API + Llama 3.3 70B). Built with pure **TypeScript** and designed with a modern, dark-mode UI.

## ✨ Features

- 🤖 **AI-Powered Code Generation:** Leverages Llama 3.3 70B via the Groq API to create responsive frontend components from simple text prompts.
- 🎨 **Tailwind CSS Styling:** Generates modern UI elements pre-styled with clean Tailwind classes.
- 🌐 **Multi-language Support:** Adapts component copy to match the language of your prompt (English, Portuguese, Japanese, Russian, Spanish, etc.).
- ⚡ **Real-Time DOM Manipulation:** Instantly previews generated HTML/Tailwind directly in the browser.
- 📋 **One-Click Code Copy:** Easily copy the generated source code with a single button click.
- 🛡️ **Type-Safe Frontend:** Written in pure TypeScript with strict asynchronous error handling.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, Tailwind CSS, TypeScript
- **AI Integration:** Groq Cloud API (`llama-3.3-70b-versatile`)
- **Tooling:** TypeScript Compiler (`tsc`), Browser-native `fetch` API
